# Rijksoverheid Sans

Deze fonts vallen **niet** onder de EUPL-1.2 van de rest van deze repository.
Ze zijn auteursrechtelijk beschermd door de Staat der Nederlanden en mogen
alleen gebruikt worden in publicaties van de Rijksoverheid of door partijen die
in opdracht daarvan werken. De voorwaarden staan in
[`LICENSES/LicenseRef-Rijkshuisstijl.txt`](../../../../../LICENSES/LicenseRef-Rijkshuisstijl.txt);
de annotatie staat in `REUSE.toml`.

Gebruik je deze invulhulp buiten dat kader, dan moet je deze bestanden
vervangen door een font waarvoor je wel de rechten hebt.

De webfont van de applicatie komt uit `@nldd/design-system`. Deze TTF-bestanden
blijven staan voor de PDF-export: pdfmake kan alleen TTF inbedden, geen woff2.
